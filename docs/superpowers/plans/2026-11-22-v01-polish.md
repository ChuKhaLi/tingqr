1. **Bộ tạo nhận `null`, số, chuỗi thay vì object** → `TingQrError('INVALID_VALUE')`, không phải `TypeError`. Task 1 test cả `null`, `42`, `'x'`.

  ```json
  "tingQrError": {

    "status": 500,
    "body": { "error": { "code": "<a code from errors.json>" } },
    "why": "The app, not the client, builds the payload, so a TingQrError is a server-side mistake; its message may describe the app's configuration and is not sent. An app that builds a QR from client input and wants 400 catches the error itself.",

  }
  ```
