## Gotchas
- **Dấu `\` bị mất** khi sửa file bằng heredoc/`sed`/`node -e`/Python heredoc trong shell này (kể cả `\uXXXX`): dùng Edit/Write.
- **Lệnh `cat > file` thiếu heredoc sẽ treo** chờ stdin.
- `python -I` bỏ qua `PYTHONIOENCODING`; in chữ Khmer ra console bị lỗi cp1252 — in giá trị ASCII (ví dụ CRC) thôi.
- `conformance/tools/crc16.py` đã có sẵn: `python -I conformance/tools/crc16.py --check "<payload>"`.
- **LSP C# hay báo lỗi giả** (kiểu "không tìm thấy" sau khi thêm file); tin `dotnet build`, không tin LSP.
- Stryker.NET trong `dotnet/` chạy mọi project test tham chiếu project bị đột biến; chạy Core từ thư mục test của Core.
- `// Stryker disable once <Kind>` che mọi đột biến loại đó trên cả dòng.
- `gen-svg.mjs` từ chối ghi khi `ts/packages/render/src` hay `conformance/tools/render` có thay đổi chưa commit; commit
  trước rồi mới sinh lại mẫu. CI cần `fetch-depth: 0`.
- Test Angular và NestJS chạy trên `dist`; `pnpm typecheck` build mọi gói trước. Windows: `tar` của Git hiểu `C:` là máy
  từ xa; npm hiểu `dir/file.tgz` là repo GitHub (dùng `./`).
- Lệnh xem tiến trình qua PowerShell `Get-CimInstance` bị auto mode từ chối.
