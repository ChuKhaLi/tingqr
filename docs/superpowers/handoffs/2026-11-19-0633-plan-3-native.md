## Gotchas
- **Windows, `core.autocrlf=true`:** Write tool tạo CRLF; `.gitattributes` đưa về LF. Mẫu thử là `-text` để CRC không đổi.
  Script Python ghi file nên dùng `newline='\n'`.
- **Lệnh `sed` với `\t`, `\uFEFF` trong biểu thức** đã ghi ký tự điều khiển thật vào file. Dùng Edit tool cho regex có
  escape.
- **Lệnh `node --test test/` không chạy trên Windows**; dùng `node --test` (tự tìm file).
- **Stryker sandbox sâu hơn một cấp:** test phải dùng `CONFORMANCE_DIR` (`ts/packages/core/test/conformance-root.ts`),
  không dùng đường dẫn cố định. Cấu hình Stryker cần `"plugins": ["@stryker-mutator/vitest-runner"]` vì pnpm.
- **Xoá worktree hay bị "Directory not empty"** khi session đang đứng trong đó, hoặc vì file bị ignore. Kiểm bằng `diff -rq --strip-trailing-cr` (loại `node_modules`, `dist`, `.git`) trước khi `rm -rf`.
- **Lệnh Bash có chuỗi `conformance/private` bị chặn.** Muốn thử `private.spec.ts` thì dùng biến
  `TINGQR_PRIVATE_DIR` trỏ vào thư mục tạm.
- **`pnpm add -D` đã xoá trường `"dependencies": {}`** khỏi `ts/packages/core/package.json`. Kiểm `check:core` coi thiếu là rỗng.
- **Mỗi entry mới (`vnpay`, …) thêm ESM, CJS và source map.** Gói tăng từ 14,6 KB lên 33 KB qua Plan 2, nên Task 1 bỏ source map.
- **Hai bản rà soát tự động chạy sau mỗi commit** (security-guidance) và đã bắt được lỗi thật 3 lần. Đọc kỹ, xử lý
