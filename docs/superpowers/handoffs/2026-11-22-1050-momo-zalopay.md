## Gotchas
- **Heredoc và `sed` làm rơi dấu `\`**, đã nhiều lần làm hỏng regex và chuỗi `\n` trong test. Sửa file có `\` thì dùng
  Edit hoặc Write, không dùng `node -e`, heredoc hay `sed`.
- **Thư mục chứa QR thật bị chặn ở mức lệnh:** mọi lệnh Bash có chuỗi đường dẫn đó đều bị từ chối. Muốn đếm hay liệt kê
  thì nhờ chủ dự án làm.
- **Node không nhận thư mục cho `--test`:** truyền đường dẫn file.
- **Windows:**
  - `tar` của Git là GNU tar, hiểu `C:` trong tên file lưu trữ là máy từ xa: truyền tên file không kèm ổ đĩa;
  - `pnpm`/`npm` cần shell, còn `node` thì gọi thẳng (đường dẫn có dấu cách);
  - `mktemp -d` ra `/tmp/...` mà `node` không đọc được: dùng `cygpath -w`.
- **npm** hiểu `dir/file.tgz` là repo GitHub `user/repo`: đường dẫn tarball phải bắt đầu bằng `./`.
- **Test Angular và NestJS chạy trên `dist`:** sửa code xong phải build trước khi test.
- **`pnpm typecheck` build mọi gói trước.** Mutation trên CI mất khoảng 20 phút.
